# 🛒 Fresh Hunt – Smart Grocery eCommerce Website

Fresh Hunt is a smart and user-friendly **Grocery eCommerce Website** developed as a mini project. It allows customers to browse grocery products, add items to their cart, place orders, and manage their shopping experience through an online platform.

The project focuses on providing a convenient digital grocery-shopping experience with features such as product management, secure user authentication, order management, and real-time updates.

## ✨ Features

* 🛍️ Browse and search grocery products
* 🛒 Add products to cart and manage cart items
* 👤 User registration and login
* 🔐 Secure authentication
* 📦 Product and inventory management
* 🧾 Order placement and order management
* 🚚 Order/delivery management
* ⭐ Product reviews and ratings
* 💬 Review sentiment analysis using Machine Learning
* ⚡ Real-time product/order updates
* 🎁 Loyalty/reward functionality

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/fresh-hunt.git
cd fresh-hunt
```

### 2. Install Dependencies

For the frontend:

```bash
cd frontend
npm install
```

For the backend:

```bash
cd ../backend
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the backend directory and add the required configuration, such as:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

Add other API keys or credentials required by your implementation.

### 4. Start the Application

Start the backend:

```bash
npm start
```

Start the frontend:

```bash
npm start
```

The application will then be available through the local development server.
